# Age of Olympus v1.4.0 Stage 7 — Divine Rule & Living Mythology

- index.html
- style.css
- game.js

New systems:
- Divine Court with private audiences and judgments
- Favors, debts, and promises that can be called in later
- Secrets, verification, concealment, revelation, exploitation, and rumor spread
- Deeper parenting for demigods and immortal children
- Divine House succession crises and rival heirs
- Dynamic artifacts created from completed legendary sagas
- Mortal dynasties founded by adult demigod descendants
- Ancestor spirits for famous dead characters
- Regional mythology: each city develops a different story about your reign
- Automatic myth creation from actual completed sagas

Save migration:
