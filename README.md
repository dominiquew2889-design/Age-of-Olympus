# Age of Olympus — Version 0.3.0: Rise of Heroes

Replace the current files in your GitHub repository with:

- `index.html`
- `style.css`
- `game.js`

Cloudflare Pages will deploy the update automatically after each commit.

## New gameplay

- Advance Year button with confirmation and yearly summary
- Recruitable legendary heroes
- Hero levels, experience, health, energy, loyalty, stats, and abilities
- Active monsters with health, strength, fear, rewards, and weaknesses
- Interactive monster battles
- Quests with hero assignment and success chances
- Divine Throne Room audiences with meaningful decisions
- Treasury with Gold, Food, Stone, Wood, Bronze, Glory, Faith, and Favor
- City management, temples, festivals, priests, and divine wrath
- Rival influence and yearly world simulation
- Automatic saving

## Save note

Version 0.3.0 uses a new save key. Your Version 0.2 save will not automatically transfer.
