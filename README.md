# Age of Olympus v0.4.0a — Interactive Greece Map

Replace your existing GitHub files with:

- index.html
- style.css
- game.js

Cloudflare Pages will redeploy automatically after each commit.

## New features

- Tappable illustrated map of Greece
- Ten city markers
- Influence-based marker colors
- Hero icons on the map
- Monster territory icons
- World event icons
- Map filters
- City detail panel
- Hero movement between cities
- Animated hero and event markers
- Existing Version 0.3 hero, monster, quest, throne, treasury, and Advance Year systems retained

This version uses a new save key and begins a new campaign.
